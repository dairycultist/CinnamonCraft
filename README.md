# CinnamonCraft

voxel engine

I'm not going to shoot too far because, I don't want to be rigorous implementing potentially useful, but definitely complex/annoying, features -- those projects already exist (e.g. Cubyz, Luanti).

featherweight! open-source! C!!

farming game? a hl inspired shooter? all with that blocky aesthetic...

imagine a binding-of-issac-like dungeon system but Minecraft

## Features

- Block rendering
- Player controller

- Pathfinding tools
- Inventory and item system

- Official modding support with Lua
- In-game mod menu
- Multiplayer (with 100% separate client-server code)
